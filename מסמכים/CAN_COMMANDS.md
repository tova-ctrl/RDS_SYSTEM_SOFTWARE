# 🛰️ מדריך פקודות CAN Bus — פרויקט FCC & ISM

קובץ זה מתעד את מזהי ה-CAN (ה-IDs), ערכי המצבים ופקודות הבדיקה הידניות לתקשורת בין מחשב הטיסה (FCC) לבין מודול מערכות ההצתה והבטיחות (ISM).

---

## 1. ניהול רשת הבדיקה (vcan0)

* **איתחול והרמת הרשת:**
  ```bash
  make vcan
  ```
* **האזנה וניטור התעבורה בזמן אמת:**
  ```bash
  make monitor
  ```

---

## 2. מילון מזהי רשת (CAN IDs Matrix)

### 🔹 פקודות והודעות מה-FCC ל-ISM (כיוון: FCC ➔ ISM)

| שם הקבוע בקוד | CAN ID (Hex) | תיאור / תפקיד ההודעה |
| :--- | :--- | :--- |
| `CAN_ID_HEARTBEAT` | **0x100** | אות חיים שוטף ממחשב הטיסה |
| `CAN_ID_ARM` | **0x101** | פקודת דריכה של מערכת ההצתה |
| `CAN_ID_DISARM` | **0x102** | פקודת נטרול/השבתה של מערכת ההצתה |
| `CAN_ID_STANDBY` | **0x103** | העברת המערכת למצב המתנה |
| `CAN_ID_MOTION` | **0x110** | עדכון נתוני תנועה / אינרציה |
| `CAN_ID_FIRE_REQUEST` | **0x120** | **פקודת הצתה רשמית** |
| `CAN_ID_RECOVERY_RESET` | **0x130** | פקודת איפוס מערכת ההתאוששות |

### 🔸 משוב ודיווחים מה-ISM ל-FCC (כיוון: ISM ➔ FCC)

| שם הקבוע בקוד | CAN ID (Hex) | תיאור / תפקיד ההודעה |
| :--- | :--- | :--- |
| `CAN_ID_STATE_ACK` | **0x200** | אישור מצב נוכחי ומעברי מצבים מה-ISM |
| `CAN_ID_FAULT_REPORT` | **0x210** | דיווח על תקלות או חריגות בבטיחות |
| `CAN_ID_HEARTBEAT_ACK` | **0x211** | אישור קבלת אות חיים (Heartbeat) מה-FCC |

---

## 3. ערכי מצבי ה-ISM (ISM States — 1 Byte Payload)

כאשר ה-ISM מחזיר הודעת סטטוס ב-ID `0x200`, הבית הראשון (`Data[0]`) מייצג את המצב הנוכחי לפי המילון הבא:


| ערך מספרי (Hex/Dec) | שם המצב בקוד | מחרוזת תצוגה (String) | תיאור המצב |
| :---: | :--- | :--- | :--- |
| **0** | `ISM_STATE_SAFE` | `"SAFE"` | מערכת מאובטחת, הצתה חסומה |
| **1** | `ISM_STATE_STANDBY` | `"STANDBY"` | המערכת בהמתנה ומוכנה לקבלת פקודות |
| **2** | `ISM_STATE_ARMED` | `"ARMED"` | **המערכת דרוכה!** מוכנה להצתה |
| **3** | `ISM_STATE_FIRING` | `"FIRING"` | **הצתה פעילה כעת** |
| **4** | `ISM_STATE_FAULT` | `"FAULT"` | המערכת במצב תקלה / השבתת חירום |

---

## 4. פקודות הזרקה ידניות לבדיקת המערכת (Test Vectors)

ניתן לפתוח טרמינל נוסף ולהשתמש בפקודת `cansend` כדי לדמות את ה-FCC או את ה-ISM לצורכי בדיקה:

### סימולציית פקודות FCC (שליחה ל-vcan0):
* **שליחת אות חיים (Heartbeat):**
  ```bash
  cansend vcan0 100#
  ```
* **שליחת פקודת דריכה (ARM):**
  ```bash
  cansend vcan0 101#
  ```
* **שליחת פקודת הצתה (FIRE REQUEST):**
  ```bash
  cansend vcan0 120#
  ```
* **שליחת פקודת השבתה מיידית (DISARM):**
  ```bash
  cansend vcan0 102#
  ```

### סימולציית תגובות ISM (שליחה ל-vcan0):
* **דיווח שה-ISM עבר למצב ARMED (סטטוס = 2):**
  ```bash
  cansend vcan0 200#02
  ```
* **דיווח שה-ISM נכנס למצב תקלה (סטטוס = 4):**
  ```bash
  cansend vcan0 200#04
  ```
* **שליחת דיווח על תקלה קריטית (FAULT REPORT):**
  ```bash
  cansend vcan0 210#
  ```
