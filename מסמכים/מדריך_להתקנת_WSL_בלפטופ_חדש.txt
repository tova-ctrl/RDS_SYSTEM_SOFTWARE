📋 מדריך העברת סביבת vcan ללפטופ החדש (בלי קומפילציה!)
============================================================

שלב 1: התקנת הלינוקס הבסיסי (WSL)
----------------------------------
במחשב החדש, פתחי את ה-PowerShell של ווינדוס כ"מנהל מערכת" (Run as Administrator) והריצי את הפקודה:
wsl --install

* ווינדוס יתקין את WSL 2 ואת אובונטו אוטומטית. 
* בסיום, בצעי הפעלה מחדש (Restart) למחשב, והגדירי שם משתמש וסיסמה בלינוקס החדש.


שלב 2: השתלת הקרנל המקומפל שלך (vmlinux)
----------------------------------------
1. קחי את קובץ ה-vmlinux שגיבית מהמחשב הישן, והעתיקי אותו לתוך תיקיית המשתמש שלך בווינדוס החדש בנתיב:
   C:\Users\YOUR_WINDOW_USERNAME\vmlinux
   *(החליפי את YOUR_WINDOW_USERNAME בשם המשתמש החדש שלך בווינדוס)*

2. באותה תיקייה בדיוק, צרי קובץ טקסט חדש ושני את השם שלו ל- .wslconfig
   *(שימי לב שאת מוחקת את סיומת ה-.txt של הקובץ)*

3. פתחי את הקובץ בכתבן (Notepad) והדביקי בפנים את השורות הבאות:

[wsl2]
kernel=C:\\Users\\YOUR_WINDOW_USERNAME\\vmlinux

4. שמרי וסגרי את הקובץ.


שלב 3: הפעלה אוטומטית של ה-vcan בכל כניסה ללינוקס
--------------------------------------------------
כדי שהלינוקס ירים את רשת ה-CAN לבד בכל פעם שאת פותחת את הטרמינל:
1. פתחי את הטרמינל של WSL (אובונטו).
2. הריצי את הפקודה הבאה כדי לפתוח את קובץ ההגדרות:
   nano ~/.bashrc

3. רדי עם החצים עד לסוף הקובץ ממש, ופתחי שורה חדשה.
4. הדביקי שם את הקוד הבא בדיוק:

# Auto-start Virtual CAN interface
if ! ip link show vcan0 > /dev/null 2>&1; then
    sudo modprobe vcan 2>/dev/null
    sudo ip link add dev vcan0 type vcan 2>/dev/null
    sudo ip link set up vcan0 2>/dev/null
fi

5. שמרי וסגרי את הקובץ: לחצי על Ctrl+O, לאחר מכן על Enter, ואז על Ctrl+X.


שלב 4: בדיקה סופית שהכל עובד 🎉
-------------------------------
סגרי את הטרמינל של WSL ופתחי אותו מחדש. הריצי את הפקודה הבאה כדי לראות שהרשת למעלה:
ip link show vcan0

אם את רואה שורות שמציגות את vcan0 במצב UP, זהו! הכל מוכן לפיתוח.
